Демонстрація box-sizing, overflow і display

1. Властивість box-sizing

content-box
Загальна ширина: 350px
border-box
Загальна ширина: 300px

2. Властивість overflow

overflow: visible

Це довгий текст для демонстрації поведінки вмісту, який не поміщається у блок заданої висоти. За значення visible текст виходить за межі блоку та залишається видимим. Додатковий текст потрібен для перевірки.

overflow: hidden

Це довгий текст для демонстрації поведінки вмісту, який не поміщається у блок заданої висоти. За значення hidden частина тексту за межами блоку приховується. Додатковий текст потрібен для перевірки.

overflow: scroll

Це довгий текст для демонстрації поведінки вмісту, який не поміщається у блок заданої висоти. За значення scroll додаються смуги прокручування. Додатковий текст потрібен для перевірки.

overflow: auto

Це довгий текст для демонстрації поведінки вмісту, який не поміщається у блок заданої висоти. За значення auto смуги прокручування з'являються лише за потреби. Додатковий текст потрібен для перевірки.
