ЛАБОРАТОРНА РОБОТА №5 — CSS властивості блоків та фону

Вміст:
- lab4_1.html — дворівневий список;
- lab4_2.html — таблиця без селекторів класів та ідентифікаторів;
- lab4_3.html — стилізована анкета;
- lab4_4.html — чотири фони з градієнтів;
- lab4_5.html — box-sizing, overflow та display;
- lab4_6.html — сайт-візитівка з демонстрацією background-властивостей;
- style.css — спільний зовнішній файл стилів;
- icons/ та img/ — локальні SVG-зображення.

Як запустити:
1. Розпакуйте архів.
2. Відкрийте будь-який HTML-файл у браузері.
3. Усі файли мають залишатися в тих самих папках, щоб шляхи до CSS та SVG працювали.
4. Для завдання 3 створено приклад анкети, оскільки файл questionnaire.html з лабораторної №3 не був доданий.

Примітка: у методичці назви файлів мають вигляд lab4_1.html ... lab4_6.html, хоча документ називається лабораторною роботою №5. Назви залишено відповідно до інструкції PDF.
